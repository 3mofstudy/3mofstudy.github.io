blog-seo-ai

部落格 SEO 小幫手・本地端 CLI

文章寫完之後，最煩的是那些 SEO 小事。把部落格文章的 .md 丟進去，用 LLM 一次搞定：挑關鍵字、寫 meta description、看懂圖片再取好檔名和 alt 文字。

到 GitHub 看看 安裝說明

一次搞定三件事

  1. 挑 SEO 關鍵字

    讀完整篇文章，提出適合的關鍵字，數量和字數上限都能調整。

  2. 寫 meta description

    產生幾則不同角度的摘要，字數範圍可自訂，挑最喜歡的一則。

  3. 圖片檔名與 alt

    看懂每張圖片，給出有意義的檔名和 alt 文字。檔名和 alt 分開挑，可以混搭不同模型的結果。

分析 → 挑選 → 套用

分析
呼叫模型產生建議，寫進 output/ 資料夾。這一步絕不修改原始檔案，中間結果也能手動改。
挑選
互動選單逐項挑：採用某個模型的建議、自己輸入，或不採用。不呼叫模型，不花錢，可以重跑到滿意。
套用
唯一會改檔的一步：改寫圖片路徑與 alt、幫圖片改名、把關鍵字和摘要寫進 front matter。可以先預覽，也會自動備份。

模型隨你選

  • Hugging Face（預設、免費額度）
  • Claude
  • OpenAI
  • Gemini

預設用 Hugging Face 的免費模型，也可以改用 Claude、OpenAI 或 Gemini。文字和圖片可以用不同模型，還會換算每次花費（新台幣），並能限制最多分析幾張圖來控制成本。

需要 Python 3.13 以上，建議用 pipx 安裝，之後在任何資料夾打 blog-seo-ai 就能用：

pipx install git+https://github.com/3mofstudy/blog-seo-ai.git
