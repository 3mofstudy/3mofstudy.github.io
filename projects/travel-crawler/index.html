出遊小幫手

今天去哪裡玩？・travel_crawler

空大 Python 課程的小組期末報告。用 Python 爬蟲從政府公開資訊蒐集全台各縣市的旅遊資料，整合到同一個平台，讓出遊前的查詢和比較變簡單。

到 GitHub 看看 使用手冊 PDF 開發文件 PDF

蒐集了哪些資料

  1. 觀光景點
  2. 活動資訊
  3. 餐飲美食
  4. 旅館民宿
  5. 天氣預報

每一類資料各有一支爬蟲程式，由組員分工完成，再由主程式整合。

系統怎麼運作

  1. 爬蟲抓資料

    五支 Python 爬蟲從政府開放資料抓取景點、活動、餐廳、旅館和天氣，用 pandas 整理。

  2. 自動更新

    主程式部署在 AWS 上定期執行，把最新資料寫進 Google 試算表。

  3. 儀表板查詢

    用 Google Looker Studio 做成儀表板，選縣市就能一次看到吃喝玩樂和天氣。

用到的技術

  • Python
  • requests
  • pandas
  • gspread
  • AWS
  • Google Looker Studio

這是六人小組的合作專題，從各自寫爬蟲、整合主程式到雲端部署和儀表板設計，一起完成。
