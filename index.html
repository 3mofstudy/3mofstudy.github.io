關於

我是露西，網路上大家叫我小墨魚。早年在醫院和大學當研究助理，從收集臨床資料、跑統計分析裡找到最喜歡的工作；後來自學 R，跨進氣象數據分析，在資料的路上越走越遠。

小墨魚異想天空工作室是我一個人的小角落。做的都是自己天天會用的東西：先解決自己的麻煩，再分享給有同樣需要的人。

有問題或想法，歡迎寫信到 contact@3mofstudy.app，或到 GitHub 留言回報。

小墨魚的日常

  • 白天：統計分析、建模、整理數據
  • 晚上：讀書、寫方格子、寫電子書

  • 假日：做一點讓生活更順手的小工具
